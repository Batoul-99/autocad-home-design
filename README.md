# AutoCAD Home Design Project

An AutoCAD academic project representing a real house design in both 2D and 3D.

## Project Overview

This project focuses on creating a real house plan using AutoCAD. It includes a 2D house layout and a 3D representation of the same design.

The project helped practice technical drawing, spatial visualization, accurate geometry, and AutoCAD drafting tools.

## Project Files

- `home-2d.dwg`: 2D house plan
- `home-3d.dwg`: 3D house model

## Skills Practiced

- 2D drafting
- 3D modeling basics
- House plan representation
- Drawing organization
- Geometry and precision
- Layers and object properties
- Dimensions and layout understanding

## Tools Used

- AutoCAD

## Project Type

Academic project - AutoCAD
